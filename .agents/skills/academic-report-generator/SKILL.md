# Academic Report Generator & Evaluator

This skill directs the agent to compile the master submission report conforming to the professor's strict evaluation standards.

## Required Report Pillars

1. **Pillar 1: Student Grounding & Rationale**:
   - Baseline student capabilities, targeted growth vectors, and thesis convergence.
2. **Pillar 2: E-Commerce Product & Market Analysis**:
   - Market need, target audience personas, competitive analysis, and commercial differentiation.
3. **Pillar 3: Immersive Engineering (3D/XR)**:
   - WebXR implementation details, Three.js scene graph, shader and lighting choices, WebGL performance.
4. **Pillar 4: AI Technologies, Multi-Agent Management & Spatial Intelligence**:
   - Multi-agent architecture in Antigravity (agents, skills, rules, MCP).
   - The AI Spatial UI / Natural Language 3D customizer.
   - Dual-documentation analysis: "Topic Aspect" vs. "AI Technologies Aspect".

## Mandatory Quality Sections

- **Visual Intelligence**: Embed architectural Mermaid diagrams, UI wireframes, code snippets, and terminal session logs.
- **Post-Mortem Analysis**: Deep dive into *"The Most Difficult Bug/Problem"* (e.g., coordinate frame mismatch between WebXR camera and orbit controls, or asynchronous token streaming latency in spatial command parsing) detailing:
  - Symptom observed.
  - Root cause investigation.
  - Mitigation strategy and code fix applied.
- **Licenses & Provenance Table**: Exhaustive table covering all libraries, assets, and APIs (MIT, Apache 2.0, BSD-3, CC-BY) distinguishing third-party code from original author creations.
- **Submission Guide**: MS Teams submission details, GitHub repository link, and invitation check for reviewer GitHub ID: `wczart`.
